# Astra

Astra ist eine moderne Dokumentenablage mit Agenten-Workflow, bei dem eingehende Dokumente automatisch klassifiziert, in passende Akten eingeordnet und intelligent einem Agenten zugewiesen werden.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Entwicklung

```bash
npm install
npm run dev
```

## Ideen für die nächste Phase

- Upload und Dokumenten-Parsing
- KI-basierte Klassifizierung
- Zuordnung zu Akten / Ordnern / Workflow-Stufen
- Supabase-Authentifizierung
- Vercel-Deployment
- Automatisierte Agenten-Queue
